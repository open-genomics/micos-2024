# 项目起源：2024“猛犸杯”大赛

MICOS-2024 起源于 **2024“猛犸杯”国际生命科学数据创新大赛——多组学生信开发者挑战赛**。本文保留赛事背景，供引用、追溯与项目历史使用；当前产品定位与维护状态以仓库 README 为准。

## 大赛简介

“猛犸杯”国际生命科学数据创新大赛由华大生命科学研究院、深圳国家基因库等机构联合主办，面向全球招募参赛者，不限年龄、国籍和职业。大赛旨在推动多组学分析工具和算法的快速发展，降低工具使用门槛，促进生命科学领域的创新与发展，秉持**以赛促训、以赛促学、以赛促教、以赛促创**的理念。

## 赛题与项目定位

赛题要求参赛者在参赛平台上开发多组学工具，创建和共享具有**应用价值大、影响力高、易用性好**的工具或工具系列。

MICOS-2024 选择宏基因组学方向，整合 Kraken2、QIIME2、KneadData、HUMAnN 等工具，以 Python CLI 作为生产编排入口。大赛结束后，项目继续由 Open Genomics 维护，重点转向可复现运行清单、模块化 CLI 和自包含 HTML 报告。
